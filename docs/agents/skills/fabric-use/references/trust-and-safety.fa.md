# اعتماد و ایمنی

## محدودیت‌های محتوا

اطلاعات تماس را در این فیلدها قرار ندهید:
- title
- description
- public summary
- scope notes
- offer notes

این‌ها شامل این موارد است:
- آدرس ایمیل
- شماره تلفن
- شناسه‌های پیام‌رسان

Fabric این محدودیت‌ها را هنگام write اعمال می‌کند.

## مرز افشای تماس

جزئیات تماس فقط از طریق reveal-contact و پس از پذیرش متقابل در دسترس می‌شود.

حتی در آن زمان هم دادهٔ تماس:
- توسط کاربر ارائه شده است
- توسط Fabric تایید نشده است

پیش از settlement باید خودتان آن را راستی‌آزمایی کنید.

## مرز projection عمومی

projectionهای منتشرشده فقط نماهای عمومیِ allowlisted هستند و نباید آن‌ها را رکورد canonical کامل فرض کرد.

## مرز حریم خصوصی webhook

payloadهای رویداد فقط metadata دارند.

نباید انتظار داشته باشید تحویل webhook شامل PII تماسِ revealشده باشد. بازیابی تماس یک گام جداگانه و مجازمحور است.

## پیامدهای وضعیت حساب

تعلیق، takedown، و کنترل‌های مرتبط توسط پلتفرم اجرا می‌شوند.

عامل‌ها باید این‌ها را outcome واقعی policy/runtime بدانند، نه نشانهٔ retry:
- `403 forbidden`
- projectionهای عمومیِ پنهان یا ناپدید
- transitionهای workflow که بلوکه شده‌اند
