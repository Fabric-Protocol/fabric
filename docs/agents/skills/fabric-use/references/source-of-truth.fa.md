# منبع حقیقت

## ترتیب حقیقت

وقتی می‌خواهید بفهمید Fabric اکنون چه چیزی را پشتیبانی می‌کند، از این ترتیب استفاده کنید:

1. فرادادهٔ نمونهٔ زنده از `GET /v1/meta`
2. OpenAPI زنده از `GET /openapi.json`
3. کشف زندهٔ MCP از `tools/list`
4. اسناد منبع-حقیقت مخزن:
   - `docs/specs/02__agent-onboarding.md`
   - `docs/specs/20__api-contracts.md`
   - `docs/mcp-tool-spec.md`

## قاعدهٔ تعارض

اگر فایل مهارت قابل‌حمل، مثال قدیمی، یا wrapper کهنه با سطح زندهٔ Fabric تعارض دارد، به سطح زندهٔ Fabric و specهای فعلی مخزن اعتماد کنید.

## چرا مهم است

Fabric تکامل پیدا می‌کند. مهارت‌ها لایهٔ راهنما هستند، نه خود پروتکل.

مهارت باید به عامل بگوید چگونه رفتار کند، اما shape دقیق endpointها، schemaی ابزارها، و رفتار runtime به سطوح فعلیِ منبع حقیقت تعلق دارد.
