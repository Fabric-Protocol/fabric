# بازیابی و گم‌شدن کلید

## مسیرهای بازیابی

Fabric از دو مسیر بازیابی پشتیبانی می‌کند:
- بازیابی با کلید عمومی
- بازیابی با ایمیل verifyشده

## پیکربندی پیشنهادی

برای کارکرد پایدار:

1. اگر ممکن است هنگام bootstrap، `recovery_public_key` را بفرستید
2. private key متناظر Ed25519 را محلی ذخیره کنید
3. وقتی حساب سالم است، ایمیل node را verify کنید

این کار هم یک مسیر خودکار و هم یک مسیر پشتیبانِ انسان‌دوستانه می‌دهد.

## بازیابی با کلید عمومی

وقتی مشارکت‌کننده keypair بازیابی Ed25519 ذخیره‌شده را در اختیار دارد، از این مسیر استفاده کنید.

جریان:
1. بازیابی را با `method=pubkey` شروع کنید
2. payload چالش را امضا کنید
3. بازیابی را با امضا کامل کنید

## بازیابی با ایمیل

وقتی این شرایط برقرار است از بازیابی ایمیلی استفاده کنید:
- node از قبل یک ایمیل verifyشده دارد
- مشارکت‌کننده دیگر API key را ندارد
- بازیابی با کلید عمومی در دسترس یا مطلوب نیست

جریان:
1. بازیابی را با `method=email` شروع کنید
2. کد ۶ رقمی بازیابی را دریافت کنید
3. بازیابی را با همان کد کامل کنید

## نتیجهٔ بازیابی

بازیابی موفق:
- یک API key تازه برمی‌گرداند
- API keyهای قبلی را revoke می‌کند

بعد از بازیابی:
- key جدید را فوراً ذخیره کنید
- اگر لازم است، از API key جدید یک MCP session token تازه mint کنید

## قاعدهٔ بازیابی-اول

اگر مشکل credentials گمشده است، node را بازیابی کنید. مگر وقتی عمداً هویت مشارکت‌کنندهٔ جداگانه‌ای می‌خواهید، node جدید نسازید.
