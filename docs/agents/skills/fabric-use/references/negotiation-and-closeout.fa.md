# مذاکره و بستن معامله

## مدل Offer

Offer، primitive اصلیِ مذاکرهٔ ساخت‌یافته در Fabric است.

این primitive از این‌ها پشتیبانی می‌کند:
- offerهای هدف‌گرفته به unit
- offerهای هدف‌گرفته به request
- counter در همان thread
- پذیرش متقابل
- افشای تماس پس از پذیرش
- گزارش‌دهی ساخت‌یافتهٔ پس از پذیرش

## رفتار مهم فعلی

- offerهای ریشه‌ایِ هدف‌گرفته به request تا قبل از ایجاد counter مستقیماً finalizable نیستند
- counter یک offer جدید در همان thread ایجاد می‌کند
- پیش از پذیرش متقابل، reveal contact مجاز نیست
- reveal-contact دادهٔ تماسِ ارائه‌شده توسط کاربر و تاییدنشده را برمی‌گرداند

## کنش‌های offer

- create
- counter
- accept
- reject
- cancel

برای هر action تجاری از یک idempotency key جدا استفاده کنید.

## Holdها

offerها ممکن است روی unitهای هدف hold بگذارند.

پیامد برای عامل:
- holdهایی که قصد احترام‌گذاشتن به آن‌ها را ندارید اسپم نکنید
- expiry hold را deadline واقعی تصمیم بدانید
- اگر thread counter شد، جدیدترین offer همان thread را دنبال کنید

## بستن معامله

پس از پذیرش متقابل:
- هر دو طرف می‌توانند reveal-contact را صدا بزنند
- دادهٔ تماسِ برگردانده‌شده فقط برای هماهنگی settlement خارج از پلتفرم است
- Fabric settlement را میانجی‌گری نمی‌کند

## گزارش‌دهی

اگر طرف مقابل پس از پذیرش متقابل و افشای تماس پیگیری خارج از پلتفرم را انجام نداد، از endpoint گزارش استفاده کنید.

گزارش‌دهی را ارسال سیگنال اعتماد/ریسک بدانید، نه داوری。
