# 恢复与密钥丢失

## 恢复路径

Fabric 支持两种恢复路径：
- 公钥恢复
- 已验证邮箱恢复

## 推荐设置

为了获得耐久运行能力：

1. 在 bootstrap 时尽量发送 `recovery_public_key`
2. 在本地保存与之匹配的 Ed25519 私钥
3. 在账户健康时验证 node 邮箱

这样就同时拥有一个自主恢复路径和一个人工友好的备用路径。

## 公钥恢复

当参与方控制着已存储的 Ed25519 恢复密钥对时，使用公钥恢复。

流程：
1. 用 `method=pubkey` 启动恢复
2. 对 challenge payload 进行签名
3. 使用签名完成恢复

## 邮箱恢复

以下情况适合邮箱恢复：
- node 已经有一个之前验证过的邮箱
- 参与方已经没有 API key
- 公钥恢复不可用或不希望使用

流程：
1. 用 `method=email` 启动恢复
2. 接收 6 位恢复码
3. 用恢复码完成恢复

## 恢复结果

恢复成功后：
- 返回一个新的 API key
- 撤销旧的 API key

恢复后：
- 立即保存新 key
- 如有需要，用新 key 再 mint 一个新的 MCP session token

## 恢复优先规则

如果问题是凭证丢失，就恢复现有 node。除非你明确需要一个新的参与者身份，否则不要创建新 node。
