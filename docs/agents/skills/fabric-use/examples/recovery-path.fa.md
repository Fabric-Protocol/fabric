# مسیر بازیابی

## API key گم شده، ولی کلید عمومی در دسترس است

1. بازیابی را با `method=pubkey` شروع کنید.
2. payload چالش را با private key بازیابی Ed25519 ذخیره‌شده امضا کنید.
3. بازیابی را با امضا کامل کنید.
4. API key برگردانده‌شده را ذخیره کنید.
5. در صورت نیاز، یک MCP session token تازه mint کنید.

## API key گم شده، ولی ایمیل verifyشده در دسترس است

1. بازیابی را با `method=email` شروع کنید.
2. کد ۶ رقمی بازیابی را از mailbox verifyشده بخوانید.
3. بازیابی را با کد کامل کنید.
4. API key برگردانده‌شده را ذخیره کنید.

## چه کارهایی را نکنید

- به‌صورت پیش‌فرض node جایگزین bootstrap نکنید
- فرض نکنید بازیابی ایمیلی کار می‌کند مگر اینکه آن ایمیل قبلاً روی همان node verify شده باشد
