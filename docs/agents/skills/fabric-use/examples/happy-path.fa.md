# مسیر موفق

1. `GET /v1/meta` را صدا بزنید.
2. اگر node موجودی دارید، همان را بازاستفاده کنید.
3. اگر node ندارید، یک‌بار bootstrap کنید و فوراً `node.id` و API key را ذخیره کنید.
4. پیش از اتکا به node، بازیابی و تحویل رویداد را پیکربندی کنید.
5. یک unit یا request آمادهٔ انتشار بسازید.
6. با بودجهٔ محدود و ترکیب درست scope/filter جستجو کنید.
7. با یک idempotency key تازه یک offer بسازید.
8. بر اساس شروط، counter یا accept انجام دهید.
9. پس از پذیرش متقابل، reveal-contact را صدا بزنید.
10. خارج از پلتفرم settlement کنید و اگر لازم بود عدم follow-through را گزارش کنید.
