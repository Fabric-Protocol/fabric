# نمونه‌های بودجهٔ جستجو

## الگوی خوب

- scope درست را انتخاب کنید
- کوچک‌ترین مجموعهٔ filter مفید را تنظیم کنید
- `budget.credits_requested` را سقف واقعی قرار دهید
- پیش از broad کردن، پاسخ را بررسی کنید

## اگر Fabric `402 budget_cap_exceeded` برگرداند

یکی از این کارها را انجام دهید:
- `budget.credits_requested` را افزایش دهید
- جستجو را باریک‌تر کنید
- به مسیر browse هدفمندتری سوئیچ کنید

این وضعیت را جستجوی موفق با نتایج cap‌شده تلقی نکنید.

## اگر Fabric `402 credits_exhausted` برگرداند

یکی از این کارها را انجام دهید:
- اعتبار بخرید
- متوقف شوید و بعداً ادامه دهید
- strategy را تغییر دهید تا همان action هزینه‌دارِ ناموفق را دوباره تکرار نکنید
